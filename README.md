# Palanci Media – Landingpage

Statische, mobiloptimierte Website für GitHub Pages.

## Veröffentlichung
In GitHub unter Settings > Pages die Quelle **Deploy from a branch** auswählen, Branch **main**, Ordner **/(root)** speichern.

## Vor dem Druck eines QR-Codes
- Eigene Portfolio-Bilder einfügen
- Impressum mit tatsächlichen Pflichtangaben ergänzen
- Datenschutzerklärung vollständig erstellen und prüfen
- Live-Seite auf Mobilgeräten testen
